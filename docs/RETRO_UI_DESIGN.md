# レトロゲームUIデザイン仕様書

## 概要

v1.3.0 にて、アプリ全体のビジュアルテーマを「レトロアーケードゲーム風」に刷新した。
学習アプリとしての機能性を維持しつつ、ゲーム感・楽しさを演出し、継続的な学習モチベーションの向上を目的とする。

## デザインコンセプト

**「ネオンアーケード」** — 1980〜90年代のアーケードゲーム筐体を彷彿とさせるダークテーマに、ネオンカラーの発光表現を組み合わせたビジュアルスタイル。

### 3つの柱

| 柱 | 説明 |
|---|---|
| **レトロ感** | ピクセルフォント、角ばったUI、CRTスキャンライン |
| **ゲーム感** | 3Dボタン、CORRECT/WRONG演出、PERFECT CLEAR表示 |
| **可読性** | 日本語はDotGothic16で読みやすさを確保、英語ラベルのみPixelフォント |

## フォント — 3層設計

| 用途 | フォント | 変数 | 備考 |
|---|---|---|---|
| 英数字見出し・骨格図・スコア | Press Start 2P → M PLUS 1 Code | `--font-pixel` | 非対応グリフ（→, ─等）は M PLUS 1 Code で補完 |
| 日本語ラベル・ボタン・カード名 | DotGothic16 | `--font-jp` | ピクセル感と日本語可読性を両立 |
| 補助文・ヒント・説明・細かいUI | M PLUS 1 Code → DotGothic16 | `--font-body` | 等幅で安定した可読性 |

- Google Fonts から3フォントを読み込み（`index.html` で `<link>` タグ指定）
- **Press Start 2P は英数字の短いラベル専用**。日本語テキストには使わない
- **`--font-pixel` の最小フォントサイズは 0.7rem**。8px倍数前提のビットマップフォントはそれ未満で潰れる
- 日本語の長文表示には `--font-body`（M PLUS 1 Code）を使用し、可読性を確保する

## UI演出

### CRTスキャンライン

`body::after` 擬似要素で画面全体に半透明の横縞を重ねる。`pointer-events: none` で操作を阻害しない。

```css
background: repeating-linear-gradient(
  0deg,
  rgba(0, 0, 0, 0.03) 0px,
  rgba(0, 0, 0, 0.03) 1px,
  transparent 1px,
  transparent 3px
);
```

### ネオングロー

`box-shadow` と `text-shadow` を組み合わせ、要素が発光しているように見せる。

```css
/* ボタンのグロー例 */
box-shadow: 0 0 8px rgba(0, 255, 136, 0.4), 0 0 24px rgba(0, 255, 136, 0.15);
text-shadow: 0 0 10px rgba(0, 255, 136, 0.5), 0 0 30px rgba(0, 255, 136, 0.2);
```

### 3Dピクセルボタン

`border-color` の明暗差で立体感を表現する。クリック時は明暗を反転させ「押し込み」感を出す。

```css
/* 通常状態 */
border-color: #66ffbb #005533 #005533 #66ffbb;

/* :active 状態（押し込み） */
border-color: #005533 #66ffbb #66ffbb #005533;
transform: translate(2px, 2px);
```

## コンポーネント別デザインガイド

### ホーム画面

- タイトルはネオンパルスアニメーション付き
- タイトル下に5つのドットが順次アニメーションで光る装飾
- メニューアイテムはホバー時に左端に `▶` カーソルが出現

### スナイパーモード

- タイマーバーは残量に応じて色が変化（緑→黄→赤）
- タイマーバー下に秒数をピクセルフォントで表示
- フィードバックオーバーレイは正解=緑枠グロー、不正解=赤枠グロー

### 解析モード

- STEP 1 / STEP 2 のステップ表示
- 選択ボタンは選択時にネオングロー付き

### 動詞一点集中

- 動詞名はピクセルフォント + ネオングロー
- パターンマップのドットは正方形（border-radius: 0）
- インラインフィードバックはボーダー付きの枠で正誤を色分け

### サマリー画面

- 全問正解時に `PERFECT CLEAR!` がネオンパルスで表示
- スコアはピクセルフォントで大きく表示

### コレクション

- カードはレアリティに応じたボーダーカラー（SR=金、R=銀、N=標準）
- SRカードにはシマーアニメーション（金色の光が流れる）
- 未所持カードはグレーアウト + `?` 表示

## レアリティスタイル

| レアリティ | ボーダー | 背景 | 効果 |
|---|---|---|---|
| SR (Super Rare) | `#FFD700` (金) | グラデーション（紺→暗い金） | ゴールドグロー + シマー |
| R (Rare) | `#888888` (銀) | グラデーション（紺→暗い銀） | シルバーグロー |
| N (Normal) | `#2a2a6e` (標準) | 単色（紺） | 標準シャドウ |

## デザイン変更時の注意点

1. **CSS変数を使う**: インラインスタイルでもハードコードを避け `var(--xxx)` を使用する
2. **ピクセルフォントのサイズ**: Press Start 2P は最小 0.7rem。英数字の短いラベルにのみ使用し、日本語テキストには `--font-jp` か `--font-body` を使う
3. **コントラスト**: ダーク背景のため、テキストの色が `#333` などの暗い色にならないよう注意する
4. **グロー乱用禁止**: 全要素にグローを付けると重くなり、メリハリもなくなる。主要アクション・見出し・正誤表示に限定する
5. **モバイル対応**: `@media (max-width: 600px)` で必ずレスポンシブ調整を行う
